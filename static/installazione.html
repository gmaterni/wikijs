wikijs — Avvio in Locale

wikijs è 100% client-side e non richiede installazione: niente build, niente backend, niente dipendenze da installare. Basta servire la cartella del progetto con un piccolo web server statico e aprire la pagina nel browser: dati e chiavi restano solo sulla tua macchina.

Perché il server locale? wikijs usa ES Modules nativi: per motivi di sicurezza i browser li bloccano con file://. Un comando e sei operativo.

1. Procurati i file di progetto

Copia o clona la cartella

Fatti dare la cartella del progetto (es. su chiavetta, archivio ZIP o clone del repository interno) e aprila da terminale:

cd wikijs
Nessuna dipendenza da installare per l'app: gli unici node_modules presenti servono solo ai test in test/kb-workflow/ (npm test).

2. Avvia il server locale

Dalla root del progetto (la cartella che contiene static/), avvia un web server statico. Il server va avviato dalla root perché l'app carica moduli e dati con percorsi relativi a static/.

Se apri static/index.html direttamente con doppio click (file://...), la pagina resterà bianca o darà errori in console: è normale, manca il server locale.

Con Python (già presente su molti sistemi)

cd wikijs
python3 -m http.server 8123

Poi apri nel browser:

http://localhost:8123/static/wikijs.html   # presentazione
http://localhost:8123/static/index.html     # app

Con Node.js

cd wikijs
npx serve . -l 8123

Poi apri nel browser http://localhost:8123/static/wikijs.html.

Con VS Code

Installa l'estensione Live Server, apri la cartella wikijs nell'editor, tasto destro su static/index.html → Open with Live Server.

3. Usa l'app

1 In locale il login Google è bypassato (user_local): entri subito, senza account.
2 Carica un documento con il pulsante Upload (.txt, .pdf, .docx, .odt), poi Menu → Knowledge Base → Crea.
3 Scrivi la domanda e premi Invia: la risposta cita solo pagine verificate [[slug]].
Consulta la guida utente completa per tutti i comandi, e il README tecnico per architettura, storage e API da console.

Hai già il server avviato?

Apri la presentazione o entra direttamente nell'app.
